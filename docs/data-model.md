# Report data model

- `project`: manifest name and version when provided.
- `analyzedAt`: ISO-8601 timestamp generated by the API.
- `summary`: aggregate counts, data coverage and heuristic health score.
- `dependencies[]`: package name, declared version, dependency group, wanted/latest versions, registry metadata, update state and vulnerability result.
- `dataQuality`: count of unavailable registry results and unknown vulnerability results, plus a limitation note.

Update states: `current`, `outdated`, `ahead`, `unknown`.

Vulnerability states: `scanned` (OSV returned a result for the exact version), `unknown` (not eligible due to a range/spec), and `unavailable` (provider failed or returned an incomplete response). A `scanned` result with zero advisories means no matching known advisories were returned at analysis time; it does not guarantee that a package is secure.

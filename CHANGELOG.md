# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-11-03

### Added
- Initial React/Vite dashboard and Express analysis API.
- npm Registry metadata and OSV exact-version vulnerability lookups.
- Dependency inventory, health summary, report filters and JSON/CSV exports.
- Browser-local analysis history and dark/light appearance settings.
- Input validation, API rate limiting, documentation, tests and GitHub workflows.

### Notes
- Vulnerability lookups for version ranges are intentionally marked unknown until lockfile resolution is implemented.
